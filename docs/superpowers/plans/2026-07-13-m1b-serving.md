**Interfaces:**
- `ddl.ensure_schema(db, graph_name) -> None` — идемпотентно: range-индексы `Sym.id/qualified_name/service`, `Chunk.id` НЕ создаём (M3); UNIQUE-констрейнт на Sym.id: сперва exact-match индекс, затем `GRAPH.CONSTRAINT CREATE <graph> UNIQUE NODE Sym PROPERTIES 1 id` через `db.connection.execute_command` (паттерн доказан doctor-probe). - `batch.upsert_nodes(g, labels: tuple[str, ...], rows: list[dict], batch_size=1000) -> int` — rows: `{"id":…, "props": {…}}`; Cypher: `UNWIND $rows AS r MERGE (n:<L1:L2> {id: r.id}) SET n += r.props`. Ошибка батча → бисекция (рекурсивно пополам; одиночная строка с ошибкой — лог warning + skip); возвращает записанные.
- `batch.upsert_edges(g, edge_type: str, rows: list[dict], known_ids: set[str], batch_size=1000) -> tuple[int, int]` — rows: `{"src","dst","props"}`; предфильтр по known_ids (оба конца) → dropped; Cypher: `UNWIND $rows AS r MATCH (a {id: r.src}) MATCH (b {id: r.dst}) MERGE (a)-[e:<TYPE>]->(b) SET e += r.props`; label-agnostic MATCH по id (индекс на Sym.id; Service/узлы без Sym-метки матчатся по свойству — допустимо на наших объёмах M1). Возврат (written, dropped).
- edge_type/labels — только из schema.EDGE_TYPES/NODE_KINDS+«Sym»/«Service» (валидация — InvariantError, защита от инъекции в f-string Cypher).
