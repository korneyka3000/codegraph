## 2. Полировка — приземлилась (проверено)

### 2.1. External HTTP-таргеты — first-class (главное улучшение)

HTTP-unresolved **36 → 29**; появился счётчик external = **7**. Семь клиент-методов,
заякоренных на env-переменные, которые Helm-карта резолвит в хосты ВНЕ воркспейса, теперь несут
флаг `external` + ссылку на env-имя + полный путь — вместо «просто unresolved».

**Влияние на трассу (доказано):** трасса активности, вызывающей внешний клиент, даёт
`confidence=1.00 (1 external exits)`, а хоп помечен **`→ external`** (не `unresolved`). Контраст
с прошлым билдом: там те же вызовы попадали в `unresolved` и роняли trace-confidence до 0.5.
Семантика стала честной: «знаем точный внешний адресат, он просто вне индексируемого среза» ≠
«не знаем, куда идёт». Плюс явный машиночитаемый сигнал «N external exits».

### 2.2. Compose-back полного пути в свойства узла — закрывает мой беклог из №3

Все **98/98** узлов-обработчиков маршрутов теперь несут КОМПОЗИТНЫЙ путь прямо в свойствах узла
(с префиксом `/api/vN/...`), а не локальный хвост. В №3 я отметил это косметическим беклогом
(«композитная идентичность жила только на канале») — теперь закрыто, карточка узла самодостаточна.

### 2.3. +1 start-mark

Старт-хопы 7 → **8**: распознана дополнительная форма запуска воркфлоу (через интерцептор).
Честное расширение покрытия, без ложных срабатываний.
